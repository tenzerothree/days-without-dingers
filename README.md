# Days Without Dinger

A single-page web app that tracks how long it's been since a selected MLB player hit a home run.

Built originally to watch Vladimir Guerrero Jr.'s power drought unfold in real time but lets you pick any team and player to track their own homerless misery.

## Features

- Select any MLB team and player via dropdowns
- Displays days since the player's last home run with a running count
- Shows player headshot linked to their MLB profile
- Includes season stats context

## Data

- MLB game data provided by Major League Baseball ([copyright](http://gdx.mlb.com/components/copyright.txt))
- Sabermetric constants from [FanGraphs](https://www.fangraphs.com/tools/guts)

## Usage

Open `index.html` in a browser. No build step required.
